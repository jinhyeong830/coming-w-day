이 프로젝트의 전체 디자인과 UX를 확인하기 위한
고품질 HTML 디자인 목업을 만들어줘.

이번 작업에서는 실제 서비스 구현이나 Next.js 프로젝트 구축을 하지 않는다.

목표는 "실제 모바일 청첩장으로 사용할 수 있을 정도로 완성도 높은
하나의 디자인 시안"을 빠르게 만드는 것이다.

코드 구조보다 디자인 완성도와 UX를 우선한다.

--------------------------------------------------
# 1. PROJECT DEFINITION
--------------------------------------------------

이 프로젝트는 일반적인 모바일 청첩장 템플릿이 아니다.

두 사람의 삶과 관계를 하나의 인터랙티브 스토리로 보여주는
premium mobile storytelling website다.

사용자는 처음에는 두 사람의 이야기를 읽고,
자연스럽게 결혼이라는 결말에 도달한다.

그리고 이야기 이후에는 실제 결혼식에 필요한
모든 정보를 쉽게 확인할 수 있어야 한다.

즉,

STORY FIRST
INVITATION LAST

라는 구조를 기본 철학으로 한다.

하지만 실제 모바일 청첩장으로 사용하기 때문에
다음과 같은 실용적인 기능은 반드시 포함한다.

- 결혼식 일시
- D-Day
- 신랑/신부 정보
- 혼주 정보
- 결혼식장 정보
- 지도
- 카카오맵 연동을 고려한 지도 영역
- 길찾기
- 대중교통
- 주차
- 셔틀버스
- 갤러리
- 계좌번호
- 계좌번호 복사
- 방명록
- 공유

--------------------------------------------------
# 2. DESIGN DIRECTION
--------------------------------------------------

전체적인 디자인 키워드:

Editorial
Luxury Minimal
Cinematic
Premium
Timeless
Interactive Storytelling

Apple 제품 페이지,
고급 독립 잡지,
뮤지엄 / 전시 웹사이트,
프리미엄 브랜드 웹사이트,
editorial magazine의 디자인 언어를 참고한다.

단, 특정 사이트를 복제하지 않는다.

"예쁜 모바일 청첩장"이 아니라
"프리미엄 인터랙티브 웹사이트"처럼 보여야 한다.

--------------------------------------------------
# 3. ABSOLUTELY AVOID
--------------------------------------------------

다음과 같은 전형적인 모바일 청첩장 디자인을 피한다.

- 꽃 장식 중심 디자인
- 리본
- 금색 장식
- 과도한 베이지
- 웨딩 일러스트
- 신랑신부 캐릭터
- 과도한 둥근 카드
- 과도한 box-shadow
- 과도한 gradient
- 템플릿 같은 UI
- 모든 내용을 카드로 만드는 디자인
- "축 결혼" 같은 전형적인 장식
- 과도하게 여성스러운 디자인
- 과도하게 귀여운 디자인
- 정보가 너무 빽빽한 레이아웃

장식보다

TYPOGRAPHY
PHOTOGRAPHY
WHITESPACE
LAYOUT
MOTION

으로 고급스러움을 만든다.

--------------------------------------------------
# 4. COLOR
--------------------------------------------------

전체적으로 절제된 컬러 팔레트를 사용한다.

기본 배경은 warm white / ivory 계열을 사용할 수 있지만
"베이지색 청첩장"처럼 보이면 안 된다.

Black / Off-white / Warm Gray를 중심으로 한다.

Accent color는 필요할 경우 하나만 사용한다.

색상은 전체 페이지에서 일관되게 사용한다.

--------------------------------------------------
# 5. TYPOGRAPHY
--------------------------------------------------

타이포그래피를 디자인의 핵심 요소로 사용한다.

영문:

SERIF + SANS SERIF 조합을 적극적으로 사용한다.

한글은 가독성이 좋은 현대적인 sans-serif를 사용한다.

예:
Pretendard

제목은 큰 크기와 충분한 여백을 사용한다.

작은 텍스트를 과도하게 사용하지 않는다.

--------------------------------------------------
# 6. MOBILE FIRST
--------------------------------------------------

이 프로젝트의 실제 사용 환경은 모바일이다.

기본 viewport는 다음을 기준으로 한다.

390px × 844px

단, desktop browser에서도 전체 디자인을 확인할 수 있도록
responsive하게 만든다.

모바일에서 다음을 특히 고려한다.

- 한 손 조작
- 터치 영역
- 읽기 편한 글자 크기
- 충분한 vertical spacing
- 긴 페이지에서의 navigation
- 이미지 loading
- 자연스러운 scroll interaction

--------------------------------------------------
# 7. GLOBAL NAVIGATION
--------------------------------------------------

페이지 상단에 Fixed Navigation을 만든다.

하지만 일반적인 모바일 청첩장처럼
메뉴 항목을 항상 길게 노출하지 않는다.

기본 상태:

--------------------------------
S&J                         MENU
--------------------------------

또는

--------------------------------
S&J                          ≡
--------------------------------

처럼 매우 미니멀하게 만든다.

Header는 항상 화면 상단에 fixed되어 있다.

과도한 shadow나 border를 사용하지 않는다.

사용자가 MENU를 누르면
Full Screen Navigation이 부드럽게 나타난다.

Navigation:

01  OUR STORY
02  INVITATION
03  WEDDING
04  VENUE
05  GALLERY
06  ACCOUNT
07  GUESTBOOK

각 항목은 해당 section으로 smooth scroll한다.

현재 사용자가 어느 section을 보고 있는지도
시각적으로 구분한다.

Navigation이 열려 있을 때에는
배경 페이지가 scroll되지 않도록 한다.

닫기 버튼을 제공한다.

Navigation animation은 elegant하고 빠르게 만든다.

# 19. INTERACTION
--------------------------------------------------

전체 페이지에 animation을 적용한다.

하지만 animation을 장식처럼 남발하지 않는다.

원칙:

- slow and elegant
- subtle
- purposeful
- smooth
- never annoying

필수 interaction:

1. Hero entrance animation
2. Fixed navigation
3. Full-screen menu animation
4. Smooth scroll navigation
5. Timeline horizontal movement
6. Timeline transition / merge
7. Section reveal
8. Gallery image transition
9. Gallery fullscreen viewer
10. Account copy feedback
11. Guestbook interaction

스크롤을 방해하거나
사용자가 기다려야 하는 animation은 사용하지 않는다.

--------------------------------------------------
# 22. IMPORTANT DESIGN DECISION
--------------------------------------------------

디자인을 만들 때
각 section을 단순한 "카드"의 연속으로 만들지 않는다.

페이지 전체가 하나의 editorial experience처럼
연결되어야 한다.

각 section마다 다른 카드 UI를 만드는 대신

- typography
- whitespace
- image composition
- line
- scale
- alignment
- subtle motion

을 이용하여 section을 구분한다.

"모바일 청첩장 템플릿"이 아니라
"프리미엄 인터랙티브 웹사이트"라는 느낌이
첫 화면부터 마지막까지 유지되어야 한다.

--------------------------------------------------
# 23. IMPORTANT IMPLEMENTATION RULE
--------------------------------------------------

내가 디자인을 직접 세세하게 지정하지 않은 부분은
네가 전문적인 웹 디자이너라고 가정하고 판단해서 결정한다.

단순하고 안전한 디자인보다
실제 서비스로 출시해도 될 정도의
강한 디자인 완성도를 목표로 한다.

여러 개의 디자인 시안을 만들지 않는다.

하나의 명확한 art direction을 선택하고
전체 페이지에 일관되게 적용한다.
